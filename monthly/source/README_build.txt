A Pythagoras Tree Grown from a Dodecahedron -- LaTeX source

Compile with pdflatex (twice):

  with author details:  pdflatex dodecahedral_tree_monthly.tex
  anonymous version:    pdflatex "\def\ANONYMOUS{}\input{dodecahedral_tree_monthly}"

Figures are in figures/ (JPEG renders, PDF line art).  If maa-monthly.sty is placed
next to the .tex file it is loaded automatically.
